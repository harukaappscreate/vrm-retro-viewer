# Sample avatar, exported as 3D for Pyxel 3

The "Pyxel 3D" export of the bundled sample avatar (Sendagaya Shibu, CC0), ready to run.

```bash
pip install pyxel numpy
pyxel run main.py
```

Arrows: walk.  X: run.  Z: punch.  SPACE: next motion.

`main.py` is `sample_3d.py` renamed, so that the folder also runs on Code & Magic (upload every file; `.py`, `.png` and `.tmx` only).

---
